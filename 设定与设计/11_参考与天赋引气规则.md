## 已确认的引气规则

用户选择：**测灵后先获得基础心法与引路机会，再按灵根、悟性、根骨计算天数；普通天赋约一至三个月，极佳天赋数日至数周。** 当前开局已改为从0岁选择关键成长经历，测灵由具体路线触发，不再直接选择7/8/10/12岁或几年后引气。

在同样悟性5、根骨5的基准下：

| 灵根 | 引气基准天数 |
|---|---:|
| 绝灵根 | 120 |
| 五灵根 | 90 |
| 四灵根 | 70 |
| 三灵根 | 45 |
| 双灵根 | 20 |
| 变异灵根 | 12 |
| 天灵根 | 7 |

计算：`天数 = max(3, ceil(基准天数 / 天赋系数))`。

`天赋系数 = clamp(1 + (悟性−5)×0.04 + (根骨−5)×0.025, 0.65, 1.5)`。

初课选择可能改变悟性，授法结束后按最终属性显示所需天数。先完整记录一次计算结果，实际经过同等天数才进入炼气一层；不额外赠修为、灵石或第二部基础心法。世界日历、家人寿元与住处租期照常推进，生平记录实际用时。安全入门段不抽强制年度风险事件，也不生成行走营生收入。保存失败回滚该次日历与入门记录。

这张表是本游戏首版尺度，源于用户确认的快慢区间。它不代表原作说某种灵根必须恰好七天或九十天。后续会用实际角色分布调整，核心规则不确定时先拿具体方案向用户确认。

已入门的旧角色不倒退重修；旧档已经确定的等待求学经历保留，未走完的测灵选择可继续接入新流程。
