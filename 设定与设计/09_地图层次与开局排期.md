# 《仙途》地图层次与开局排期

更新：2026-10-22，第四十五批。用于回答“各层地图何时丰富”和“计划中的开局何时做”。这里的后续内容不是已经实现的功能。

## 当前交付

青石县从五个公共房间扩为二十处：十字街、东市商街、百工坊、牙行、青石拍场，新增县学门前、县衙前街、县衙照壁、仓廪外院、水井巷、西城民巷、药铺后院、来安客栈、东西横街、南门大街、北/南/东城门、城东河埠。可居住的出身住处与已购产业另按权限加入，不计在这二十处公共地点里。

布局采用地方方位坐标和公共街路，不再用一棵“入口连全部设施”的树代替县城；点地图地点会逐段走过真实连接，没有地图下方重复按钮。三名有年龄、寿元、身份的街巷人物参与第一条五步回执事件链。十一处既有区域已分配不同的现有房间方位模板，但其中大多数还没有丰富的独有内容。

## 开发顺序

| 顺序 | 范围 | 这一步要交付什么 |
|---|---|---|
| 第四十五批已完成 | 县城布局与第一条地方短链 | 二十公共地点、沿路移动、回执五步、完成/失约/中断标记与人物持续回应 |
| **紧接下一轮优先** | **六出身正式开局短链** | 出生家庭、身份日常、第一次具体委托/选择、按个人时间线入道与获得基础心法的真实过程；与已交付住处/权限接通 |
| 开局基础验收后 | 出身村、青云观、城南坊市、县域外围 | 里正/田地/药坡、弟子舍/传功处/药圃、摊区/委托处；每处有具体人物与可完成事务 |
| 随后府域阶段 | 云安府、白水渡、落霞坊市、太岳外山 | 商会/客舍/官署办事处、码头/仓栈/船行、专业工坊与门派工役/考核；把现有拍卖接稳定商路货源 |
| 对应高阶玩法阶段 | 结丹上院、优质灵脉、古境、灵眼/守关、边境商路 | 先有准入条件、资源来源、具体人物、双向路线与事件后果，再补区域与内部场景 |
| 开局之后并按玩法接入 | 凡钱、家庭日常、D2双模式实际差异 | 真实货币来源与支付、生活费用、失败代价/有限救援/成长压力；分别验收，不用指引开关冒充规则差异 |

不以完整九州大图、凡钱或D2全部做完作为六条开局的前置，也不等所有县城都制作完才做开局。宏观州、国、府县用于地理与政治结构，优先做有内容的代表地区，不逐一堆出数千个同质空县。阶段顺序是本轮明确调整；不承诺未经实施的日历完成日期。

## 下一轮六条开局的具体范围

| 出身 | 应做起步过程 | 约束 |
|---|---|---|
| 寒门散修 | 家中日常 → 向里正/采药人学做事 → 接触游方口诀 → 按个人时间线入道与第一次营生选择 | 家贫和家人意愿有实际表现，不凭空给产业 |
| 宗门外门弟子 | 弟子住处安置 → 初次工役/门规 → 监院传授基础调息 → 与同门建立第一段往来 | 已有本门身份，不重新收拜门费；床位不是永久产权 |
| 没落家族子弟 | 回旧宅 → 查残卷/家账 → 与长辈商议修复及生计 → 接续家传基础法 | 不自动抹去家族责任，不赠整族资产 |
| 世家嫡系 | 宗族日常与族学 → 领取有额度的起步支持 → 选择相应义务 → 正式启蒙 | 支持有来源与额度，家族大宅和钱库不变个人财物 |
| 妖血遗孤 | 藏身处与养育者 → 血脉征兆 → 学会藏息/应对外界 → 选择第一次出行 | 既有亲属与身世连续，不新增灵根境界硬锁 |
| 魔道弃徒 | 脱离旧师门的余波 → 坊市暂居安置 → 残页调息 → 选择隐瞒/寻求帮助与第一次谋生 | 对应凡界别院背景，不让幼童随意往返灵界主宗 |

这些是下一轮制作目标，当前仍只有旧童年选择、基础心法授予和持续住处，尚未交付上述六条互动式开局。

开局验收：六身份×两模式逐一可完成；角色/家人身份和时间连续；步骤不重复赠钱物或功法；基础法与已知权限一致；有选择、回应和后果；可保存恢复。已有成年/修行存档继续原进度，不强行重播童年，不补领一整套重复开局奖励。新旧档和传承都须分别测试。

## 地点不能只凑名字

每个新地区应有所属与控制者、连接和所需时间、独有用途、具体人物、可完成事务、后果与存档状态。县学/县衙等公共场所先开放门前和外院，不把走到门口等同于可以取用书库、官粮或领取公产。后续逐处补活动，不能把一批有描述的节点宣称为完整县城社会模拟。
