当前版本：第四十七批「天赋引气、身世与器物循环」，已续改零岁开局、地域地图、出身分支与炼气主辅配功/回合斗法（2026-10-23）。正常入口仍为 `prototype/index.html`。详见[本批说明](版本说明/第四十七批_天赋引气身世与器物循环.md)。

**开发查看：双击 `开发者检查.cmd`，或从游戏右下角“开发者检查”打开总览。** 无需依赖普通角色逐步解锁；独立测试局可定位地点、选灵根与境界、备齐资源、试演事件，自动档和三个手动档均与正常局分开。

新角色选择九条童年路径与相符籍贯，记录家庭、族属与社群。从0岁选择出生家庭，再以养育、学习、寻访引荐等关键成长篇章推动年月；不直接选择测灵年龄，灵根在路线中的实际查验后揭示。之后完成安置、授法，按灵根、悟性与根骨计算实际引气天数。已有修行角色不倒退重演，旧档不重复领资源。九条出身各有两条地方引荐路，入门后可实际履行并当面交代；这仍是首批短链，不代表全部家庭长剧情完成。

新抽取灵根采用已确认B方案：普通家庭依次为绝灵根8%、五灵根30%、四灵根32%、三灵根20%、双灵根7%、变异2.5%、天灵根0.5%；修行家族为2%、15%、28%、32%、16%、5%、2%。目前明确记有家族传承的没落家族、世家分支使用修行组，其余暂按普通组；组织依附和族属不自动提升概率。概率为可玩角色有灵根的条件分布，不是世界人口比例；已有角色与未测灵角色已抽定的资质不重抽。运行配置与路线在 tools/opening49.js。

凡钱与灵石分别记账：凡物只用凡钱，修仙物品用灵石。可从县城货街短工起步，到百工坊买凡铁和工艺册，制作并装备短剑；再采集灵木、取得器谱和炉位，炼制低阶法器。顶部“收支账目”可核对流水。[实体内容清单](设定与设计/12_首批实体内容清单.json)与[参考/引气规则](设定与设计/11_参考与天赋引气规则.md)可供开发核查。

**当前进度统一看[凡界开发统合计划](设定与设计/06_凡界开发统合计划.md)顶部对账。** M0基础已交付，M1县域内容与M2功法/器物仍在补全；M3/M4只有局部样例，M5渡界与M6凡界全程验收未完成。地图已读取角色地域并显示国家、州府县；九地仍共用地图/经济模板，大众和硬核仍仅默认指引不同。人手契约的既有排期见[后续排期](设定与设计/13_人手培养与后续排期.md)；本轮已按用户要求先接入炼气功法与斗法闭环，人手契约排期保留。

流派由功法、招式和器物组合形成，不设置单一职业选择。炼气篇首版已接一主修、最多两辅修与原有两术法槽，逐部定义专项作用及实际存在的修炼/突破/寿元条目，不为所有功法统一添加三项收益。辅修按品阶、熟练度与适配折算，小幅叠加；运气冲突产生回合真元负担。首版平衡参数集中在 tools/qi51.js，可继续调整，不照搬参考作品数值。分析与建议默认在聊天交付，维护现有资料。

已接事项现补充实际地点、行动按钮、材料进度和完成/交代方式，童年引荐及护路约定进入追踪；折叠时仍显示第一项下一步。起步约定只在约定地点完成行动才算履行。专项检查见 tools/scene46-guide-check.cjs。

**基础闭环（前次交付）：修行页「炼气行程」，或县城入口 / 道观前院的「当地传习」。** 当时新增九种心法/招式抄本，购买后在行囊阅读，再到功法研习与配功。剑术、近身、御器形成三类可混搭打法；实际法器是御器招式的前提。演练不掉落、不计护路进度；实战到可猎妖地区的山野深处选敌，寻找耗7日。战斗逐回合选择攻击、术法、守势、调息、用药或撤退，显示敌方意图，战中锁定配置且可存档续战。气血与真元在战外持续，休养七日恢复，长期伤势沿用年限/丹药处理。三段护路分别面向初、中、后段，回县城入口实际交付，报酬只结一次；修为增长及筑基突破沿用实际世界钟。tools/qi51-check.cjs 验证普通开局资源、实际营生/买装/旅行/学习/护路与修行至筑基的受控路径；并非全随机剧情、所有配功平衡或全凡界验收。凡界整体目标保留，筑基以后的新斗法尚未扩展。

**炼气路线与百艺续改：从修行页「各路修行与百艺」，或县城入口/道观前院的同名入口进入。** 剑术、筋骨近身、御器、五行、符箓、阵法、灵兽、傀儡、炼丹、炼器十条方向均有三段传习，可混搭、不选职业。初中后段篇章按真实修为和上一段经历取得；新增51部心法/术法，各自定义条目，五行15术法分别具有破甲、缠绕、水护、灼伤与土盾效果。抄本买后仍须阅读、研习。接取时记录实际经办人（县中沈案生或道观执事），回原经办人处核验；丹器交付实际成品，酬金从经办人钱匣扣除，成品记入对方收货。

新增19项工艺覆盖纸墨制符、六类阵具、木傀及升级部件、三种丹药、炼气法器/护衣，需实际工艺、工位、材料、灵石与时日。旧制作入口也受进阶条件约束。铁匠去世后不会重生，材料可改走坊市行商、野外采集和山林寻灵木；配方页逐项显示来源。

阵法分地点使用：攻击、防护、困敌可在野外布临时战阵，一战或离开本地区后失效；聚灵、养脉、示警及小型护阵可放在有使用权的个人居室/院落，离家保留、在原地维护供能。固定阵不改变公产产权，不在街道任意布置，不提高地区灵气门槛资格。阵修可选战斗传习或纯辅助传习。灵兽、傀儡各一个独立协同位，可同时携带；救助/喂养/训练/养伤和制作/升级/驱动/维修均有实物与时间结算，协同指令占本回合操作。

心法、术法与路线表在 tools/qi52-data.js，物品、工艺和功能在 tools/qi52.js。tools/qi52-check.cjs 逐条核验十方向三段、固定/临时阵、两个协同位和旧档；另外逐方向从普通开局实际取得资源、完成三段并修至炼气圆满，关闭随机剧情并固定采样，未直接改层数、发钱或延寿。该样本不代表全部随机局、全部流派组合或完整凡界验收；大型护山攻防、灵兽繁育、傀儡群控与跨代契约尚未扩展。仅维护现有说明与清单，无新增交付文档。

## 启动

双击根目录的 `启动游戏.cmd`，或用原来的浏览器打开 `prototype/index.html`。正常入口刷新先显示首页，点击“续前缘”才读取自动存档；行动自动保存功能保留。开发测试入口仍直接恢复自己的独立存档。游戏离线运行，HTML引用本地美术和沙盒脚本、样式，请保留整个 `prototype/`，不能只移动HTML。

第四十七批保留入口路径和存档键。仍请使用原来的浏览器和原项目入口继续原档。旧规则存档需要选择本局模式；备份或模式写入失败会停止升级并提示，选择前不会用普通保存覆盖原档。

本地存档由原浏览器保存，入口路径和存档键不变。旧档会补基础功法和人物登记；仅有道侣标记、缺少具体人物ID时，保留待核记录，不生成替代人物。测试使用独立浏览器上下文，没有接触玩家日常浏览器存档。


同一地点内点击场景地点移动时，保留正文滚动位置与局部地图拖动位置；切换页面、跨地区或进入事件时正常显示新内容。位置仅属于界面状态，不写入角色存档。

## 玩法入口

- 修行：修炼、闭关、突破，获取并研习功法，选择主修心法和术法。
- 场景：选房间、接触人物，向商人交易、工匠学艺，到炉坊制作、宗门执事处办事。
- 行囊：分类查看、使用、装备、阅读书册、布置便携工具。
- 家园：租院、买宅、置办洞府，建丹房、器室、药圃，管理仓库和人手委派。
- 人物：档案、关系、宗门、近况，以及存档、设置和族谱。

本版九条童年路径各有基础心法。人物关系需要当面交谈、互助与相处，道侣、结拜、师承均指向已存在的人。场景中的地图入口提供九州、诸国和修士分布概览。

可从「青石县→商街／炉坊／牙行」开始。经过十四个游戏日后，关注「青石药讯」，找王掌柜选择供药、议价或往返白水渡运药；不参与时商队也会逐步恢复供应。详见 [第三十七批说明](版本说明/第三十七批_沙盒药路.md)。百草铺已加入事前登记的药徒与接盘药商，原掌柜已故后清账三十日，再按人物与资金决定接续、转让或关铺；旧账和运药约定可由新掌柜承接。详见 [第三十八批说明](版本说明/第三十八批_百草铺交接.md)。地方经营见 [第三十五批说明](版本说明/第三十五批_地方沙盒.md)，人物、开局与关系规则见 [第三十六批说明](版本说明/第三十六批_人物与世界校准.md)。
