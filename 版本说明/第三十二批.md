# 第三十二批 · 青绿山水视觉重制

更新日期：2026-10-21。基于已更名为《仙途》的第三十一批继续开发。

## 已落地

- 开局改为山水长卷封面，支持新建角色、续前缘、寻找手动旧卷；建角表单采用宣纸与青绿样式，修正旧深色输入框。
- 修行主页增加山水场景、地点与纪年标题，统一 HUD、行动区、底栏、弹窗、行囊及设置的材质与色彩；手机状态栏压缩为两行。
- 县、州域、凡界九州、灵界五域接入独立绘画底图，九灵眼网络沿用灵界美术并重画关隘关系。地图仍保持“界 → 州域 → 县”的结构。
- 地名改为可交互图牌，保留原路线和境界限制，支持键盘进入、缩放、手机横向滑动；远地与人口统计折叠到地图下方。
- 修正旧地图样式拦截县内图牌点击、非青州面包屑仍显示青州、地图层级切换保留旧滚动位置等问题。
- `prototype/maps/地图图册.html` 更新为五幅完整画面，可独立查看，不修改游戏存档。

## 范围与限制

这是地图与界面的视觉重制，没有新增灵界旅行、远方州内探索或数值平衡。青州以外的州域保持“远方见闻”，共享示意性州域底图；主修行页暂共用山水场景，不是每个地点一张专属画面。未验证安卓/iOS 安装包或真机触控，手机验证为浏览器窄屏。旧工具 uicheck.js 仍因 DOM 模拟不适配新版初始化而不能直接使用。

## 备份与恢复

更新前的入口、地图图册与 README 位于 `版本归档/第三十二批视觉重制前_20261021_103938/`。关闭页面后，将其中对应文件复制回原路径即可恢复第三十一批更名版。新增美术资源与工具可以保留；恢复 HTML 不会同时回滚浏览器中的游戏存档。

## 开发文件

`tools/visual32.css` 和 `tools/atlas32.js` 是这批视觉层的源码副本，运行时版本已嵌入 prototype/index.html。`apply-visual32.py` 仅供从更新前版本执行一次迁移，包含重复执行保护；后续修改需同步源码与 HTML。`visual32-check.cjs` 执行浏览器验证并从运行时地图函数刷新静态图册。
